# Guia de Instruções: M.A.E. Menu Editor (Versão 1.9)

## 1. Visão Geral

O M.A.E. Menu Editor é uma ferramenta para criar e editar menus em formato JSON. Ele permite adicionar, editar, reordenar e excluir itens de menu, além de importar e exportar os dados em arquivos JSON.

## 2. Carregando um Arquivo JSON Existente

1. Clique no botão "Escolher arquivo" para selecionar um arquivo JSON.
2. Após selecionar o arquivo, clique em "Carregar JSON".
3. Se o carregamento for bem-sucedido, os itens do menu aparecerão na seção "Resultado".

## 3. Adicionando um Novo Item ao Menu

1. Preencha os campos:
   - ID: Identificador único para o item (ex: "mae-start")
   - Categoria: Categoria do item (ex: "M.A.E.")
   - Assunto: Título do item (ex: "Início do Curso")
   - Descrição: Detalhes sobre o item
   - URL: Link associado ao item
2. Certifique-se de que "Adicionar" está selecionado no campo "Ação".
3. Clique em "Adicionar/Modificar".

## 4. Editando um Item Existente

1. Clique no botão "Editar" ao lado do item que deseja modificar.
2. Os campos serão preenchidos com as informações do item.
3. Faça as alterações necessárias.
4. Certifique-se de que "Substituir" está selecionado no campo "Ação".
5. Clique em "Adicionar/Modificar" para salvar as alterações.

## 5. Excluindo um Item

1. Clique no botão "Deletar" ao lado do item que deseja remover.
2. Confirme a exclusão na caixa de diálogo que aparecerá.

## 6. Reordenando Itens

1. Clique no botão "Ativar Reordenação".
2. Arraste e solte os itens na ordem desejada.
3. Clique em "Desativar Reordenação" quando terminar.

## 7. Salvando o Menu

1. Após fazer todas as alterações desejadas, clique no botão "Salvar JSON".
2. Digite um nome para o arquivo (sem a extensão .json) quando solicitado.
3. O arquivo será baixado automaticamente.

## 8. Copiando o Nome do Arquivo Carregado

1. Após carregar um arquivo JSON, um botão "Clique para Copiar Nome do Arquivo" aparecerá.
2. Clique neste botão para copiar o nome do arquivo para a área de transferência.

## 9. Abrindo as Instruções

- A qualquer momento, você pode clicar no botão "Abrir Instruções" para acessar um guia detalhado de uso.

## Dicas Adicionais

- Certifique-se de preencher todos os campos ao adicionar ou editar um item.
- O ID de cada item deve ser único. Se tentar adicionar um item com um ID já existente, você receberá um alerta.
- A reordenação dos itens é salva automaticamente, mas lembre-se de clicar em "Salvar JSON" para baixar o arquivo atualizado.
- Sempre verifique se os dados estão corretos antes de salvar o arquivo JSON.
