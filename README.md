Guia de Instruções: M.A.E. Menu Editor (Versão 1.9)1. Visão GeralO M.A.E. Menu Editor é uma ferramenta para criar e editar menus em formato JSON. Ele permite adicionar, editar, reordenar e excluir itens de menu, além de importar e exportar os dados em arquivos JSON.2. Carregando um Arquivo JSON Existente
Clique no botão "Escolher arquivo" para selecionar um arquivo JSON.
Após selecionar o arquivo, clique em "Carregar JSON".
Se o carregamento for bem-sucedido, os itens do menu aparecerão na seção "Resultado".
3. Adicionando um Novo Item ao Menu
Preencha os campos:

ID: Identificador único para o item (ex: "mae-start")
Categoria: Categoria do item (ex: "M.A.E.")
Assunto: Título do item (ex: "Início do Curso")
Descrição: Detalhes sobre o item
URL: Link associado ao item


Certifique-se de que "Adicionar" está selecionado no campo "Ação".
Clique em "Adicionar/Modificar".
4. Editando um Item Existente
Clique no botão "Editar" ao lado do item que deseja modificar.
Os campos serão preenchidos com as informações do item.
Faça as alterações necessárias.
Certifique-se de que "Substituir" está selecionado no campo "Ação".
Clique em "Adicionar/Modificar" para salvar as alterações.
5. Excluindo um Item
Clique no botão "Deletar" ao lado do item que deseja remover.
Confirme a exclusão na caixa de diálogo que aparecerá.
6. Reordenando Itens
Clique no botão "Ativar Reordenação".
Arraste e solte os itens na ordem desejada.
Clique em "Desativar Reordenação" quando terminar.
7. Salvando o Menu
Após fazer todas as alterações desejadas, clique no botão "Salvar JSON".
Digite um nome para o arquivo (sem a extensão .json) quando solicitado.
O arquivo será baixado automaticamente.
8. Copiando o Nome do Arquivo Carregado
Após carregar um arquivo JSON, um botão "Clique para Copiar Nome do Arquivo" aparecerá.
Clique neste botão para copiar o nome do arquivo para a área de transferência.
9. Abrindo as Instruções
A qualquer momento, você pode clicar no botão "Abrir Instruções" para acessar um guia detalhado de uso.
Dicas Adicionais
Certifique-se de preencher todos os campos ao adicionar ou editar um item.
O ID de cada item deve ser único. Se tentar adicionar um item com um ID já existente, você receberá um alerta.
A reordenação dos itens é salva automaticamente, mas lembre-se de clicar em "Salvar JSON" para baixar o arquivo atualizado.
Sempre verifique se os dados estão corretos antes de salvar o arquivo JSON.
